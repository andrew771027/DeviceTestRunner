# Device Test Runner v1.2.0 Acceptance Criteria

Baseline: Git tag `v1.2.0`

- [x] Every run creates an identifiable artifact directory.
- [x] stdout and stderr can be persisted as artifacts.
- [x] The execution result exposes its artifact directory and metadata.
- [x] `SubprocessExecutor` is the command execution abstraction.
- [x] The sample configuration completes through the artifact/report pipeline.

Release decision: Accepted by tag `v1.2.0`.
