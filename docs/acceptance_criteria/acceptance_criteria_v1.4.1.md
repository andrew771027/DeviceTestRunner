# Device Test Runner v1.4.1 Acceptance Criteria

Baseline: Git tag `v1.4.1`

- [x] CSV validation checks required columns and minimum data rows.
- [x] CSV validation safely reports missing, unreadable, malformed, or non-file targets.
- [x] JSON validation checks required nested paths.
- [x] JSON expected values preserve type-sensitive comparison.
- [x] Content-validation options load correctly from YAML.
- [x] Invalid CSV or JSON content affects final run status and report output.
- [x] v1.4.0 validation rules remain compatible.

Release decision: Accepted by tag `v1.4.1`.
